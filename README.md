# IO List Creation (ABB / PLC Projects)

Automated IO list generation using Python and Excel formatting.

## 🚀 Overview
This project helps automation engineers generate structured IO lists quickly, reducing manual effort and errors during DCS/PLC project development.

## 🧰 Tech Stack
- Python
- openpyxl (Excel automation)
- Google Colab (development/testing)

## ✨ Features
- Auto-generate IO list in Excel format
- Column width & formatting control
- Easy customization for different projects
- Reusable template structure
